# OpenHood · Service Bay style guide

The visual style guide for OpenHood, an auto repair shop app for customers and service advisors.

**Live page:** https://yongjies-cmu-s26.github.io/openhood-style-guide/

It covers the logo, color, typography, page layout and spacing, buttons, icons, dialogs, menus, forms, tables and design patterns (including navigation). Every element has a live sample and the CSS that draws it.

- Fonts: Overpass and Overpass Mono (SIL Open Font License), loaded from Google Fonts
- Palette: navy `#032B43`, blue `#3F88C5`, teal `#136F63`, red `#D00000` and amber `#FFBA08` (status only)
